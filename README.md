# ЛЕКАЛО — Pattern Studio

Бесплатное приложение для построения выкроек белья и эластичных топов по индивидуальным меркам. Один и тот же интерфейс работает как самостоятельная Windows-программа и как устанавливаемая веб-версия для телефона, планшета или другого компьютера. Регистрация и сервер приложения не нужны: мерки обрабатываются на устройстве пользователя.

**Веб-версия для проверки:** [viktortown-ui.github.io/lingerie-patterns](https://viktortown-ui.github.io/lingerie-patterns/)

> Статус низа белья: **готово к пробному образцу**. Мягкий бралетт и топ пока имеют статус **экспериментальная основа**. Геометрия и печатный масштаб проверяются автоматически, но посадку и поддержку нужно подтвердить макетом и примеркой до раскроя дорогого материала.

## Что уже есть

- классические трусики: высокая, средняя и низкая посадка; три линии ноги; full/classic/cheeky;
- стринги и танга с отдельной настройкой узкой части спинки;
- экспериментальный мягкий бралетт без каркасов и экспериментальный базовый эластичный топ без рукавов;
- пять встроенных фасонов трусиков, стрингов и танга, которые открываются поверх индивидуальных мерок;
- личная библиотека фасонов: сохранение, строгий импорт/экспорт и повторное применение настроек без копирования мерок тела;
- безопасный локальный импорт статических SVG-лекал с отдельным экраном просмотра и скачиванием нормализованной копии;
- семь связанных мерок вместо условного стандартного размера;
- одиннадцать связанных мерок верха для бралетта и топа;
- отдельные параметры поперечной и продольной растяжимости, восстановления ткани и резинки;
- калькулятор растяжимости образца ткани;
- варианты обработки талии и ноги, положения/ширины/подкладки ластовицы;
- разные припуски по технологическим краям и нулевой припуск на сгибе;
- живой чертёж с линиями кроя, строчки, сгиба, долевой, направления растяжения и надсечками;
- безопасные именованные регуляторы A1/A2/B1/B2/C1 для формы низа: их можно менять числом или перетаскивать прямо на чертеже;
- обратимая история мерок, опций и регуляторов с кнопками «Отменить / Вернуть»;
- полноэкранный просмотр, истинное вписывание чертежа и калибровка экрана;
- проверки сопряжения боковых швов и возможности провести пояс через ягодицы;
- ориентировочный расход ткани и резинки, персональная последовательность пошива;
- PDF A4, A3, Letter и A0, настоящий нахлёст листов и отдельная контрольная страница;
- SVG в реальном размере, детерминированный DXF R12 в миллиметрах и сохраняемый проект JSON;
- размерный ряд XS–XL с независимым перестроением каждого размера по явным прибавкам и ZIP-пакет из DXF + manifest;
- локальные профили и несохранённые черновики отдельно для каждой модели, резервная копия и строгий импорт;
- русский и английский интерфейс, светлая и тёмная темы, работа без интернета после первого успешного запуска и кэширования текущего релиза;
- отдельные компоновки для телефона, планшета/split-screen, ноутбука и большого desktop; на телефоне есть нижняя навигация и крупные сенсорные элементы.

## Запуск на Windows

Готовая portable-сборка находится на странице [GitHub Releases](https://github.com/viktortown-ui/lingerie-patterns/releases). Распакуйте ZIP целиком и дважды щёлкните **`LEKALO.exe`**. Это отдельная программа с собственной иконкой и окном: CMD, PowerShell, локальный сервер и открытая вкладка браузера ей не нужны.

На этом компьютере после локальной сборки можно запускать ярлык **`ЛЕКАЛО`** в папке проекта. Файлы **`Запустить приложение.cmd`**, **`Остановить приложение.cmd`** и **`Проверить локальный запуск.cmd`** оставлены только как запасной браузерный режим и средство диагностики.

Windows-программа использует установленный Microsoft Edge WebView2 Runtime и хранит свой профиль в `%LOCALAPPDATA%\Lekalo\WebView2`. На Windows 11 Runtime обычно уже есть; если его нет, программа покажет понятное сообщение со ссылкой на официальный установщик. Portable-предпросмотр пока не подписан сертификатом, поэтому при первом запуске скачанного файла Windows может показать SmartScreen.

Данные браузерной и Windows-версии находятся в разных локальных профилях и автоматически не смешиваются. Профили можно перенести через резервную копию JSON; импортированные SVG при необходимости скачиваются и добавляются отдельно.

### Сборка Windows-программы из исходного кода

На Windows запустите PowerShell в папке проекта:

```powershell
.\desktop\Build-Desktop.ps1
```

Сценарий сначала запускает все тесты, проверяет SHA-256 официального WebView2 SDK, компилирует программу штатным .NET Framework 4.8 и выполняет реальный smoke-тест окна. Результат появляется в `dist-desktop`.

### Телефон, планшет и другой компьютер

Откройте [веб-версию](https://viktortown-ui.github.io/lingerie-patterns/) в современном браузере. Через меню браузера её можно добавить на главный экран и запускать как PWA. После первого полного открытия текущая версия и четыре основы доступны без сети.

GitHub Pages здесь используется как публичная beta-площадка. До переноса на отдельный домен вводите только тестовые или не чувствительные мерки: несколько проектов владельца размещены на общем origin `viktortown-ui.github.io`, а браузер разграничивает локальное хранилище по origin, не по папке сайта. Подробности — в [политике приватности](PRIVACY.md).

Не открывайте `index.html` напрямую через `file://`: браузеры блокируют модульный JavaScript в таком режиме. Для старого браузерного режима стартовый файл поднимает только локальный адрес `http://127.0.0.1:57021` и не публикует его в сеть. Логи этого режима находятся в `%LOCALAPPDATA%\PatternStudioLocal`.

## Библиотека фасонов и свои заготовки

На главном экране есть пять готовых наборов настроек для двух проверяемых основ низа. Кнопка **«Открыть фасон»** переносит в редактор только фасон, обработку и ограниченные поправки A/B/C; сохранённые ранее мерки выбранной основы остаются личными и не входят в шаблон.

Свой вариант можно сохранить из редактора как шаблон, затем открыть, скачать в JSON или импортировать обратно. Импорт строгий: идентификатор и версия модуля должны точно совпасть, неизвестные поля и настройки блокируются. Это защищает от тихого применения старого шаблона к изменившемуся алгоритму построения.

Кнопка **«+ Добавить SVG»** предназначена для легально полученных заготовок. Файл разбирается полностью локально: исходная SVG-разметка не вставляется в страницу и отбрасывается, активный контент, ссылки, стили и неподдерживаемые элементы блокируют импорт. В библиотеке остаются только проверенные линии и SHA-256 отпечаток источника.

Импортированный SVG всегда помечается **«Личное • не проверено»**. Это статическая геометрия: она не получает формул, мерок, параметрического редактирования, размерного ряда, подтверждения посадки или производственного статуса. Если масштаб не распознан, сначала сверьте известный контрольный отрезок и исправьте/калибруйте исходник; раскрой по такому файлу без проверки недопустим.

В приложении предусмотрены три разных пути расширения:

1. **Новый фасон существующей основы** — настройте опции и A/B/C, затем сохраните шаблон; это быстро, но не создаёт другую конструкцию.
2. **Своя или открыто лицензированная заготовка** — импортируйте SVG для безопасного хранения и просмотра; он остаётся статическим до ручного переноса конструкции в модуль.
3. **Новый вид одежды** — добавляется отдельным параметрическим модулем со своими мерками, формулами, деталями, проверками швов и физическими макетами. Контракт и минимальный каркас описаны в [`docs/MODULE_API.md`](docs/MODULE_API.md).

Для открытого каталога подходят собственные построения, работа нанятого конструктора с передачей прав или источник с явно совместимой лицензией и обязательной атрибуцией. Наличие PDF/SVG в интернете или в рабочей папке само по себе не даёт права включать его в бесплатное приложение. Лежащие рядом PDF-примеры поэтому не копируются в код. В качестве легального исследовательского каталога отмечен FreeSewing: у проекта есть открытый репозиторий и основы/изделия от белья и спортивного топа до футболки, юбки и брюк; перед переносом конкретного дизайна всё равно отдельно проверяются его актуальная лицензия, авторство и пригодность формул.

## DXF и размерный ряд

DXF содержит отдельные слои `CUT`, `SEAM`, `NOTCH`, `GRAIN`, `TEXT`, явные миллиметры и служебные данные деталей. Каждый файл повторно читается встроенным строгим парсером; контрольный файл также успешно открыт, сохранён и снова прочитан независимой библиотекой `ezdxf`.

Это структурно проверенный обменный DXF, но **не** сертификат AAMA/ASTM и не гарантия совместимости с конкретным раскройным комплексом. Перед производством откройте файл в CAD выбранного цеха, проверьте единицы, масштаб, замкнутость, надсечки и смысл слоёв, затем изготовьте контрольный макет.

Размерный ряд XS–XL — прозрачный пересчёт мерок с новым построением каждого размера. Это полезная градация по правилам мерок, но пока не промышленная поточечная градация базового лекала.

## Правильная печать

1. Скачайте PDF нужного формата.
2. Сначала распечатайте только контрольную страницу.
3. Выберите **100% / Actual size** и отключите **Fit / Подогнать / Shrink**.
4. Проверьте линейкой квадраты 50 × 50 и 100 × 100 мм.
5. Только после совпадения масштаба печатайте листы лекал и совмещайте одинаковую область нахлёста 10 мм.

Подробный сценарий: [`docs/USER_GUIDE.md`](docs/USER_GUIDE.md).

## Приватность и файлы

- нет аккаунта, аналитики, рекламы и отправки мерок на сервер;
- текущий проект и профили сохраняются в локальном хранилище браузера;
- личные шаблоны фасона сохраняются локально и принципиально не содержат мерок тела;
- импортированные статические SVG хранятся локально в IndexedDB; если браузер запретил хранилище, они доступны только до закрытия сеанса;
- резервную копию профилей и каждый проект можно скачать как JSON;
- коммерческие PDF-примеры из рабочей папки не входят в репозиторий и не копируются приложением.

Полное описание данных, хранения и удаления: [`PRIVACY.md`](PRIVACY.md). Сообщить об уязвимости: [`SECURITY.md`](SECURITY.md).

## Разработка

Сборка не требуется. Нужен современный браузер. Для тестов требуется Node.js 20+:

```powershell
npm test
```
